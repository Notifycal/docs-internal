- AWS Lambda (NodeJS 22.x)
- AWS API Gateway
- DynamoDB for storing data
- Typescript
- [AWS Lambda Powertools](https://github.com/aws-powertools/powertools-lambda-typescript)
- [middy](https://middy.js.org/)
- [AWS SDK v3](https://docs.aws.amazon.com/AWSJavaScriptSDK/v3/latest/)
- [Google authentication](https://www.npmjs.com/package/google-auth-library)
- [jsonwebtoken](https://www.npmjs.com/package/jsonwebtoken)
- [zod for schema validation](https://zod.dev/)
- [jest](https://jestjs.io/)

And for mimicking API Gateway during local development, we use:

- ExpressJS
- Nodemon
- esbuild

Other tooling

- eslint and plugins and configs
- prettier
